SC Security Reports Analyzer

Analyse the Security Central JSON reports — category & VM assignments, audit rules, and query coverage — and produce an interactive visual report.

SC Pipeline Pod Log Analyzer

Analyse ncm-sc namespace pod logs — Flink CDC events, BQL query stats, ML worker status, cron job outcomes, and errors.

When enabled, the kubeconfig is pulled from Prism Central via SSH, then kubectl logs is run for every ncm-sc pod. Disable to analyse a pod-logs directory already on disk.
Directory containing *.log files collected from ncm-sc namespace.

Network Log Analyzer

Analyse the ncm-network-log-receiver log to produce a structured report on FlowBatch delivery rates, NATS publish latency, error patterns, and hourly breakdown.

When enabled, the kubeconfig and receiver log are pulled from Prism Central via SSH + kubectl. Disable to analyse a log file already on disk.
