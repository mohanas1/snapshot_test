      Workload simulation (guest SSH / disk churn)
      

        Eligible guests: IP in Prism inventory, powered on, configured RAM above the minimum (MiB from Prism; default >250), and not skipped by name rules. Guest SSH counts use the server inventory cache from when this page loaded (reload after changing skips). Limit how many get SSH with a number or percent (e.g. 100, 50%); leave blank for all eligible.
        Each run uses sshpass + ssh to the guest and runs:
        Delete — rm -f …*.img ·
        Create — openssl | dd with your bs and count ·
        Add — append ·
        Update — overwrite ·
        All mix — random per VM.
