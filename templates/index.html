VM guest disk churn (SSH)

Eligible guests: IP in Prism inventory, powered on, configured RAM above the minimum (MiB from Prism; default >250), and not skipped by name rules. Use Fetch VMs first, then preview uses that cache (no second groups API call). Limit how many get SSH with a number or percent (e.g. 100, 50%); leave blank for all eligible. Each run uses sshpass + ssh to the guest and runs: Delete — rm -f …*.img · Create — openssl | dd with your bs and count · Add — append · Update — overwrite · All mix — random per VM.

Requires sshpass + ssh on this server. Disable with BULK_SNAP_GUEST_NO_SSHPASS=1. Guest reachability may still differ from Prism-reported IPs; trial with a small limit first.
